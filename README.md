# ClipSHIFT - WIP

A cross-platform app for syncing your clipboard via ntfy.sh.

## Installation

- make sure you have the ntfy.sh app
- make sure "Broadcast messages" is enabled in ntfy's advanced settings
- install clipshift and input the base url and topic you want to use
- send clipboard via clipshift's notification or share target
- when clipboard message received, set clipboard via notification
